# ECTE408 – Image and Video Processing Labs

My MATLAB solutions for the ECTE408 lab exercises (University of Wollongong). Each `LabN` folder has its scripts, my `notes.md` for the lab, the small test images the scripts read, and the output figures.

| Lab | Topic |
|-----|-------|
| 1 | Getting started with MATLAB |
| 2 | Basic image operations |
| 3 | Image enhancement using point operations (histogram equalisation) |
| 4 | Image processing in the spatial domain (filtering, median filters, edge detection) |
| 5 | Geometric transformation of images (rotation, zoom) |
| 6 | Colour image processing |
| 7 | Convolutional neural networks and image classification |
| 8 | Deep learning and object detection (YOLOX on a BDD100K subset) |
| 9 | Image processing in the frequency domain (2-D DFT) |
| 10 | Discrete cosine transform and image compression |
| 11 | Video processing in MATLAB and Simulink |

## Not included

These are left out to keep the repo small and avoid redistributing course material:

- The lab handout PDFs and logbook templates
- `Lab7/Traffic_Sign_Recognition_Dataset/` and `Lab8/BDD100K-Subset/` (datasets and trained detector `.mat` files)
- The `.avi` videos for Lab 11

You'll need to add those yourself before running Lab 7, Lab 8 or the Lab 11 video scripts.

## Requirements

MATLAB with the Image Processing Toolbox. Labs 7–8 also need the Deep Learning Toolbox and the Computer Vision Toolbox.
